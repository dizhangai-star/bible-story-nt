# 光之窗 · 新約 · The New Covenant

The New Testament told by light in one cathedral window — the sequel to 《光之窗 · Windows of Light》
(`../bible-story`, the Old Testament): the same stone hall, the facing window, seven chapters (Nativity to the
New Jerusalem), about 2:30, drawn entirely in code. Stained-glass renderer vendored from lemo-opuscar (`sg/`,
see `sg/LICENSE-lemo-opuscar.txt`); needs the shared video kit at `../_kit`.

See `TREATMENT.md` for the story and `PROGRESS.md` for the state of the work.
